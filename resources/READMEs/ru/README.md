<h2 id="как-создавать-моды">🗂 Как создавать моды</h2>

### 1. Создайте папку мода
Создайте папку с `.json` файлом

### 2. Добавьте изображения
Если вы используете кастомные изображения:
- загрузите их в папку `/images` внутри вашего мода (**рекомендуется**)
- или поместите их напрямую в папку мода

### 3. Задайте символы для фигур
```json
"SYMBOLS": {
  "pawn": "pawn",
  "king": "king",
  "rook": "rook",
  "knight": "knight",
  "bishop": "bishop",
  "queen": "queen",
  "spearman": "spearman",
  "star": "star"
}
```

### 4. Опишите информацию о фигурах
```json
"PIECE_TYPES": {
  "pawn": { 
    "name": "spearman", 
    "symbol": "spearman", 
    "desc": "пешка, которая атакует клетку прямо перед собой",
    "role": "pawn", 
    "tier": 1, 
    "xpReq": 1,
    "special": "spear_attack"
  }
}
```

- **`name`** — отображаемое имя фигуры
- **`symbol`** — символ, определённый в `SYMBOLS`
- **`desc`** — описание фигуры
- **`role`** — специальная роль:
  - `king` — может делать рокировку, потеря всех королей означает поражение
  - `pawn` — может превращаться, доступен взятие на проходе
  - `rook` — участвует в рокировке
- **`tier`** — уровень эволюции
- **`xpReq`** — количество XP, необходимое для эволюции (`-1` = без эволюции)
- **`special`** — специальная способность
  - `spear_attack` — атака клетки впереди
  - `revenge` — уничтожает фигуру, которая её взяла
  - `teleport` — телепортация на любую пустую клетку
  - `explode_n` — уничтожает всё в радиусе n при взятии или если фигуру взяли
  - `detonate_n` — уничтожает всё в радиусе n при взятии или если фигуру взяли, кроме пешек и королей
  - `explode_all_n` — уничтожает всё в радиусе n при взятии или если фигуру взяли
  - `range_capture` — взятие без перемещения
  - `swap_ally` — меняется местами с союзной фигурой
- **`ghost`** — может проходить сквозь n фигур (необходимо указать n)
- **`immortal`** — не может быть взята

> [!WARNING]
> Вы должны переписать логику всех стандартных фигур

> [!TIP]
> Логика стандартных фигур уже описана в тестовом режиме — вы можете использовать её

### 5. Опишите дерево эволюции
```json
"EVOLUTION_TREE": {
  "pawn": ["star"],
  "mutant": [],
  "king": [],
  "rook": [],
  "knight": [],
  "bishop": [],
  "queen": []
}
```

> [!NOTE]
> В этом дереве эволюции пешка может эволюционировать в star

### Финальная структура `.json`
```json
{
  "SYMBOLS": {...},
  "PIECE_TYPES": {...},
  "EVOLUTION_TREE": {...}
}
```

### Финальная структура мода
```text
mod/
 ├── images/
 └── mod.json
```

<h2 id="движок">⚙️ Движок</h2>

Игра использует собственный движок

Движок использует minimax, alpha–beta pruning и сортировку ходов
