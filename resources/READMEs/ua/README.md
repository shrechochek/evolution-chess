<h2 id="як-створювати-моди">🗂 Як створювати моди</h2>

### 1. Створіть папку моду
Створіть папку з `.json` файлом

### 2. Додайте зображення
Якщо ви використовуєте кастомні зображення:
- завантажте їх у папку `/images` всередині вашого моду (**рекомендовано**)
- або розмістіть їх безпосередньо в папці моду

### 3. Задайте символи для фігур
```json
"SYMBOLS": {
  "pawn": "pawn",
  "king": "king",
  "rook": "rook",
  "knight": "knight",
  "bishop": "bishop",
  "queen": "queen",
  "spearman": "spearman",
  "star": "star"
}
```

### 4. Опишіть інформацію про фігури
```json
"PIECE_TYPES": {
  "pawn": { 
    "name": "spearman", 
    "symbol": "spearman", 
    "desc": "пішак, який атакує клітинку прямо перед собою",
    "role": "pawn", 
    "tier": 1, 
    "xpReq": 1,
    "special": "spear_attack"
  }
}
```

- **`name`** — відображувана назва фігури
- **`symbol`** — символ, визначений у `SYMBOLS`
- **`desc`** — опис фігури
- **`role`** — спеціальна роль:
  - `king` — може робити рокіровку, втрата всіх королів означає поразку
  - `pawn` — може перетворюватися, доступне взяття на проході
  - `rook` — бере участь у рокіровці
- **`tier`** — рівень еволюції
- **`xpReq`** — кількість XP, необхідна для еволюції (`-1` = без еволюції)
- **`special`** — спеціальна здібність
  - `spear_attack` — атака клітинки попереду
  - `revenge` — знищує фігуру, яка її взяла
  - `teleport` — телепортація на будь-яку порожню клітинку
  - `explode_n` — знищує все в радіусі n під час взяття або якщо фігуру взяли
  - `detonate_n` — знищує все в радіусі n під час взяття або якщо фігуру взяли, окрім пішаків і королів
  - `explode_all_n` — знищує все в радіусі n під час взяття або якщо фігуру взяли
  - `range_capture` — взяття без переміщення
  - `swap_ally` — міняється місцями з союзною фігурою
- **`ghost`** — може проходити крізь n фігур (потрібно вказати n)
- **`immortal`** — не може бути взята

> [!WARNING]
> Ви повинні переписати логіку всіх стандартних фігур

> [!TIP]
> Логіка стандартних фігур уже описана в тестовому режимі — ви можете використати її

### 5. Опишіть дерево еволюції
```json
"EVOLUTION_TREE": {
  "pawn": ["star"],
  "mutant": [],
  "king": [],
  "rook": [],
  "knight": [],
  "bishop": [],
  "queen": []
}
```

> [!NOTE]
> У цьому дереві еволюції пішак може еволюціонувати в star

### Фінальна структура `.json`
```json
{
  "SYMBOLS": {...},
  "PIECE_TYPES": {...},
  "EVOLUTION_TREE": {...}
}
```

### Фінальна структура моду
```text
mod/
 ├── images/
 └── mod.json
```
